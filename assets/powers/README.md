# Directorio de Imágenes de Poderes

Este directorio debe contener las imágenes de los poderes configurados en `config/powers.json`.

## Archivos esperados:

### Poderes Básicos:

- `fire.png` - Poder de Fuego
- `water.png` - Poder de Agua
- `earth.png` - Poder de Tierra
- `air.png` - Poder de Aire
- `lightning.png` - Poder de Rayo
- `poison.png` - Poder de Veneno
- `ice.png` - Poder de Hielo
- `shadow.png` - Poder de Sombra

### Poderes Combinados:

- `steam.png` - Combo Fuego + Agua = Vapor
- `lava.png` - Combo Fuego + Tierra = Lava
- `plasma.png` - Combo Fuego + Rayo = Plasma
- `dust_storm.png` - Combo Tierra + Aire = Tormenta de Arena
- `acid.png` - Combo Agua + Veneno = Ácido

## Formato recomendado:

- **Tamaño**: 64x64 píxeles o mayor
- **Formato**: PNG con transparencia
- **Estilo**: Iconos claros y reconocibles

## Nota:

Si no tienes las imágenes, el overlay funcionará igual pero mostrará solo los nombres de los poderes. Puedes agregar las imágenes más tarde sin necesidad de reiniciar la aplicación.
