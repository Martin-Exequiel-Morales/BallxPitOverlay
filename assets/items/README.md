# Directorio de Imágenes de Items

Este directorio debe contener las imágenes de los items configurados en `config/items.json`.

## Archivos esperados:

### Armas:

- `sword.png` - Espada

### Armaduras:

- `shield.png` - Escudo
- `helmet.png` - Casco
- `boots.png` - Botas

### Consumibles:

- `potion_health.png` - Poción de Vida
- `potion_mana.png` - Poción de Maná

### Accesorios:

- `ring_power.png` - Anillo de Poder
- `amulet_protection.png` - Amuleto de Protección

### Especiales:

- `crystal_energy.png` - Cristal de Energía
- `orb_wisdom.png` - Orbe de Sabiduría

## Formato recomendado:

- **Tamaño**: 64x64 píxeles o mayor
- **Formato**: PNG con transparencia
- **Estilo**: Iconos claros que representen el tipo de item

## Nota:

Si no tienes las imágenes, el overlay funcionará igual pero mostrará solo los nombres de los items. Puedes usar iconos gratuitos de sitios como:

- [Flaticon](https://www.flaticon.com/)
- [Icons8](https://icons8.com/)
- [OpenGameArt](https://opengameart.org/)
