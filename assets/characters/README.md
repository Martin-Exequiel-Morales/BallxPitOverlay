# Directorio de Imágenes de Personajes

Este directorio debe contener las imágenes de los personajes configurados en `config/characters.json`.

## Archivos esperados:

- `fire_mage.png` - Mago de Fuego
- `water_priest.png` - Sacerdote del Agua
- `earth_warrior.png` - Guerrero de Tierra
- `air_assassin.png` - Asesino del Viento
- `lightning_striker.png` - Invocador de Rayos

## Formato recomendado:

- **Tamaño**: 128x128 píxeles o mayor
- **Formato**: PNG con transparencia
- **Estilo**: Retratos o avatares de los personajes

## Uso:

Estas imágenes se pueden mostrar en el selector de personajes o en tooltips para dar más contexto visual al overlay.

## Nota:

Las imágenes de personajes son opcionales. El overlay funciona perfectamente sin ellas.
